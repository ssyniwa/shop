Food Stand Management Simulation
10種類の食材を組み合わせてお客さんの好みに合わせた料理を提供し、10日間の生存と繁盛を目指す経営シミュレーションゲームです。

🍳 ゲーム概要
プレイヤーはフードスタンドの店主となり、毎日来店するお客さんの注文（3つの食材の組み合わせ）に応じた料理を提供します。
売上から固定費やランダムコストが引かれるため、在庫管理と資金繰りがゲームクリアの鍵を握ります。

開発言語: Python (Pygame)

対象日数: 10日間（10日生存でゲームクリア）

初期資金: 3,000G

🥕 食材システム
全10種類の食材を駆使して料理を作ります。

肉・その他: Beef, Pork, Chicken, Egg, Spice

野菜・穀物: Cabbage, Cheese, Tomato, Bread, Rice

※3つの食材の組み合わせによって、画面上に生成された美味しそうな料理画像が表示されます。

🕹️ ゲームの流れ
注文受付フェーズ (SELECT)

来店したお客さんの「Wants（希望する3つの食材）」を確認します。

手持ちの在庫から食材を3つ選んで料理を完成させます。

営業・リザルト (RESULT)

料理のスコア（お客さんの満足度）に応じた売上と、固定費・ランダムコスト（諸経費）が計算されます。

評価が高いと翌日のお客さんの人数が増え、低すぎると減ってしまいます。

ショップフェーズ (SHOP)

1つ150Gで不足した食材を仕入れ、在庫を補充して次の日に備えます。

資金がマイナス（破産）になるとゲームオーバーです。

🛠️ 必要要件・実行方法
動作環境
Python 3.x

Pygame

インストールと実行
以下のコマンドを実行してゲームを起動します。

Bash
# Pygameのインストール
pip install pygame

# ゲームの実行
python main_11.py
